# Roadmap

## 0.1 — extracted technical preview

- Installable Python distribution and CLI
- Local all-in-one mode
- Self-hosted server and remote agent mode
- Codex thread discovery and detail view
- Managed tasks, progress events, cancellation, and approvals
- Desktop and mobile PWA interface
- Synthetic demo and screenshot workflow

## 0.2 — personal remote access

- One-time device enrollment codes
- Per-device revocable credentials
- Encrypted local configuration store
- Notifications for pending approvals
- Connection diagnostics and upgrade command

## 0.3 — multi-tenant hosted mode

- Tenant-scoped users, nodes, sessions, and tasks
- Database-enforced ownership checks
- Key rotation and device recovery
- Configurable metadata-only synchronization
- End-to-end encrypted transcript option
